# puentetablas.es

Web de la AA.VV. Puente Ibérico (Puente Tablas, Jaén), publicada con GitHub Pages.

- `/halloween/` → Halloween 2026 · Hospital 1880 (web del evento + minijuego en `/halloween/juego/`)
- `index.html` → de momento redirige a `/halloween/`
- `CNAME` → dominio personalizado `puentetablas.es`

Las páginas se generan desde `web/_fuentes/` con `python3 construir.py`; no editar a mano `halloween/index.html` ni `halloween/juego/index.html`.
